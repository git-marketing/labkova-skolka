# 🐾 Labková Škôlka

Vzdelávacia hra v prehliadači pre deti okolo 4 rokov s psíkmi z Labkovej patroly.

Stačí otvoriť `psia-skolka-ucenie.html` v prehliadači (najlepšie Chrome alebo Edge so slovenským hlasom).

## Hry (16)
- **Labková patrola:** Spoznaj tím, Kto pomôže?, Čí je tieň?, Kvíz
- **Farby, tvary a čísla:** Balóny podľa farieb, Tvary, Počítanie do 10, Veľký a malý
- **Hlavička a logika:** Čo bude ďalej?, Čo sem nepatrí?, Pexeso, Kde je psík?
- **Svet okolo nás:** Nálady, Počasie, Triedenie odpadu, Maľovanka

Za správne odpovede sú hviezdičky a za každých 5 hviezdičiek nový odznak.

`psia-skolka-ucenie-povodna.html` je pôvodná verzia.

Neoficiálny fanúšikovský projekt na domáce použitie; PAW Patrol je ochranná známka jej vlastníkov.
